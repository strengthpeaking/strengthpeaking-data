# StrengthPeaking Powerlifting Datasets

Open strength and powerlifting datasets published by
[StrengthPeaking.com](https://strengthpeaking.com/).

## Raw Powerlifting Averages by Year

Five-year averages for the best successful squat, bench press and
deadlift, grouped by sex, age group, competition weight class and year.

Source competition data:
OpenPowerlifting

Processed and published by:
StrengthPeaking.com

Canonical dataset page:
https://strengthpeaking.com/openipf-raw-strength-averages

## Downloads

- CSV: datasets/openipf-raw-strength-averages.csv
- JSON: datasets/openipf-raw-strength-averages.json

The files in this repository are automatically synchronized with
StrengthPeaking.com.
